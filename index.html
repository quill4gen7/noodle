A link instead of a screenshot

An agent calls cad_snapshot and sends a URL. The link stays on that result while the workflow moves on.

  • Pieces you can hide, solo and invert — the state lives in the URL hash.
  • Timelines play; ≡ Tracce gives every movement its own slider, so you play the order.
  • Works on a phone: bottom sheet, tap to select, double-tap to frame.

▦ Sezioni — long code, read as nodes

Agents write long CodeBlocks. Instead of making them assemble catalogue nodes, noodle reads the block's structure from its AST — the code is never rewritten.

  • Sections from the block's own headers, or grouped by what each statement builds.
  • A part built up over several sections shows as a chain of steps, each with its preview.
  • Inputs, outputs, values and time per section; agents get the same as cad_codeblock_sections.

Safe with an agent in the loop

An agent edits the graph over MCP or HTTP while you have it open.

  • Every save names the version it was edited from; a concurrent edit is merged, never overwritten.
  • Each run has its own files, can be stopped, and never publishes a half-written result.
  • Validated, title-addressable edits, atomic batches, /measure and /lint for geometry facts.

Exports that know where they came from

  • 📦 Bake: every visible node as its own STEP + STL, zipped with a manifest.
  • The library tells you which node wrote each file, and whether the graph changed since.
  • STL · STEP · 3MF · glTF · SVG · DXF, and the whole UI works offline.
